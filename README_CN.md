## 检测模块

- Microsoft 账号登录验证（Hit / Bad / 2FA / Ban）
- Minecraft 所有权 + 自动设名 + 皮肤
- Hypixel 封禁检测 + 数据查询
- Xbox Gamertag + 设名 + 游戏所有权
- Outlook 收件箱扫描（关键词过滤 + HTML 保存）
- 支付卡检测
- 订阅检测（Game Pass 等）
- 订单历史检测
- 地区检测
- Microsoft Rewards 积分查询
- Fortnite 账号关联检测
- OneDrive 文件扫描 + 下载
- IMAP 邮箱验证
- BIP-39 助记词扫描
- 多链钱包余额查询（BTC / ETH / LTC / DOGE / TRX / SOL + 代币）
- DonutSMP 数据检测（金币/碎片/游戏时间/击杀等）
- DonutSMP AutoPay（自动转账金币）

## 自动化

- Autobuy（自动购买）
- Autogift（自动礼品码）
- Auto Hanging（自动挂号 + 自定义域名）

## SukiMC 对接

- SukiMC 商户 API 对接（自动上架 Hit 账号）
- 按 SKU 代号自动路由（unban / nobc / banned + 等级门槛 + rank 要求）
- 自定义不上架规则（黑名单：按 rank / 等级 / 净值 / 披风条件过滤）
- 上架统计（已上架 / 重复 / 失败 / 跳过）
